# 小词快练 · 公开试用

给演员练台词的小工具。导入剧本、选择角色，一次开始，持续对词。

**[直接试用](https://xliu21722-sys.github.io/xiaoci-kuailian-trial/)** · **[Windows / Mac 下载和使用说明](https://xliu21722-sys.github.io/xiaoci-kuailian-trial/help.html)**

浏览器版无需 GitHub 登录或安装开发工具。首次使用需下载约 190 MB 中文识别与声音资源，随后在自己的电脑上运算。不上传麦克风录音，不调用计费识别接口。

提供网页版和下载客户端两个入口。网页版仅支持离线声音。使用Fish请下载客户端。Windows 提供 x64 与 ARM64；Mac 提供 M 系列与 Intel。客户端最低 macOS 13 / Windows 10。特别老旧系统不支持。

## 使用

1. 点上面的试用链接。
2. 选“苏晴”，点“开始对词”，允许麦克风。
3. 听到对手说完后，说自己的台词。结束后在“录音”里回听、导出或单独回练。

也可以导入自己的 TXT、Word 或文字型 PDF。原剧本不会被回练副本覆盖。

## 试用范围

这是 0.4.0 跨平台预览版。Windows 和 Intel Mac 尚无对应实机验收，见[版本说明](https://github.com/xliu21722-sys/xiaoci-kuailian-trial/releases/tag/v0.4.0-trial.1)。Mac 为本地签名，未完成 Apple 公证；Windows 尚无发行者签名。系统可能拦截安装，优先使用浏览器入口。

离线声音与识别不产生语音 API 费用。Fish 声音与克隆音请在下载的客户端中使用，需各人自己的账户；工具不承诺平台未来额度或收费规则，不自动切换收费模型。网页版仅支持离线声音，无需 Fish。

剧本和录音保存在各自电脑或浏览器。GitHub 不保存使用者练习数据。清理网站数据会删除浏览器历史，请导出重要录音。公开文件不含作者密钥、私人剧本和练习录音。

以上仅为节奏参考，最终表演以导演现场要求为准。
